## ✨ Features
* **100% Offline Support:** Fully functional without an internet connection, keeping your financial data private and secure on your device.
* **Full CRUD Operations:** Smoothly Add, Read, Update, and Delete your income and expense entries.
* **Real-time Balance Calculation:** Dynamically updates total income, expenses, and current balance immediately upon adding or deleting data.
* **Clean UI:** Designed with modern UI components and custom dialog boxes for a professional look.

---

## 🛠️ Tech Stack & Components
* **Language:** Kotlin
* **UI Design:** XML Layouts, Material Design components, and Custom Dialogs.
* **Database:** **Room Database** (for storing all financial data locally on the device).
* **Asynchronous Tasks:** Kotlin Coroutines for safe and non-blocking database operations.
